## What I'm building
- **[Unvibe](https://github.com/ShadowEsu/Unvibe)**: a free Mac and Windows app. Select code in any app, press a shortcut, and it explains the code in plain English beside your editor. TypeScript, Electron, React, Next.js, Supabase, Claude API. https://unvibe.site
- **[Time Machine](https://github.com/ShadowEsu/Time-Machine)**: open source (MIT). It saves a project before Claude Code acts, runs the project's own tests on each save point in a separate git worktree, and brings back the newest one that passes. https://time-machine.company
- **Jaymini**: an AI team workspace where AI Teammates' drafts wait for a person's approval. https://jaymini.org
